================================================================
  RETROSHOP DB — GUIDA AL RIPRISTINO DAL BACKUP
================================================================

Il file di backup è: Database/retroshop_db.sql
Contiene i DATI delle tabelle (INSERT INTO), NON la struttura.
La struttura delle tabelle viene creata da SQLAlchemy all'avvio
del backend (database.py → Base.metadata.create_all).

================================================================
  PREREQUISITI
================================================================

- PostgreSQL installato e in esecuzione su localhost:5432
- Python con le dipendenze del backend installate (pip install -r requirements.txt)
- Il file retroshop_db.sql aggiornato (generato da genera_backup.py)

================================================================
  STEP 1 — GENERARE UN BACKUP AGGIORNATO (facoltativo)
================================================================

Se vuoi prima aggiornare il backup con i dati attuali del DB:

  python genera_backup.py

Il file retroshop_db.sql verrà sovrascritto con i dati attuali.

================================================================
  STEP 2 — ELIMINARE IL DATABASE ESISTENTE (se necessario)
================================================================

Apri un terminale e digita:

  psql -U postgres

Poi dentro psql:

  DROP DATABASE IF EXISTS retroshop_db;
  \q

  ATTENZIONE: questo cancella tutti i dati presenti. Fallo solo
  se vuoi ripartire da zero con i dati del backup.

================================================================
  STEP 3 — CREARE IL DATABASE VUOTO
================================================================

  createdb -U postgres retroshop_db

================================================================
  STEP 4 — CREARE LE TABELLE (struttura)
================================================================

Avvia il backend una volta per far creare le tabelle a SQLAlchemy:

  python server/server.py

================================================================
  STEP 5 — IMPORTARE I DATI DAL BACKUP
================================================================

  psql -U postgres -d retroshop_db -f "<directory del file .sql>"

Oppure tramite pgAdmin:
  1. Apri pgAdmin → connettiti al server locale
  2. Seleziona il database retroshop_db
  3. Apri il Query Tool (ALT+SHIFT+Q)
  4. File > Apri file → seleziona retroshop_db.sql
  5. Premi F5 (Esegui)

================================================================
  STEP 6 — AGGIORNARE LA PASSWORD (se necessario)
================================================================

Se la password del tuo PostgreSQL è diversa da "biar", modifica
la riga nel file:

  backend/database/database.py  →  riga 7

  SQLALCHEMY_DATABASE_URL = "postgresql://postgres:TUA_PASSWORD@localhost:5432/retroshop_db"

================================================================
  STEP 7 — VERIFICA
================================================================

Avvia il backend e controlla che risponda correttamente:

  cd "c:\Users\aless\Desktop\Sito_tecnologie_web - React\backend"
  python server/server.py

Oppure verifica direttamente in psql:

  psql -U postgres -d retroshop_db
  SELECT COUNT(*) FROM utenti;
  SELECT COUNT(*) FROM annunci;
  \q
